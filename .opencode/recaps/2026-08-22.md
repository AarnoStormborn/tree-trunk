## 2026-08-22 — Diff readability + startup splash banner

### Goal
Test the diff view with multi-file changes and clean up how it renders; then add a startup splash banner (options → picked small wordmark, startup splash, dismiss-on-first-result).

### Done
- **Multi-file diff cleanup (PR #9, merged):** each changed file now renders a clean full-width header bar (path + `new file`/`deleted`/`renamed` tag) instead of 4 raw metadata lines (`diff --git`, `index`, `---`, `+++`); blank line between files; hunk-separator rules only between hunks within a file. Applied to both unified (`internal/ui/diffrender.go`) and side-by-side (`diffsplit.go`) renderers. New helpers, theme `diffFileBar` + `DiffFileBarBg`, tests.
- **Startup splash banner (PR #10, OPEN):** `internal/ui/splash.go` — centered figlet "small" wordmark in accent color + spinner "finding your repos…" via `lipgloss.Place`; repos stream into the list incrementally (auto-select first).
- **Splash visibility fix (PR #10):** banner previously dismissed instantly on fast scans (~300ms), invisible to user. Now hides only after BOTH a ~1.2s minimum (`tea.Tick` → `splashTimerMsg`) AND first result — visible ~1.2s on fast scans, longer on big `$HOME`. Verified live at t+0.5s (seen) / t+1.6s (dismissed).
- Docs: `docs/design/04-tui-layout.md` §0.
